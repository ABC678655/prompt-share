CHARACTER INFORMATION — EDIT ONLY THIS SECTION



CHINESE NAME:

[角色中文名]



ENGLISH NAME:

[Character English Name]





Use the provided TARGET CHARACTER reference as the primary and authoritative source for character identity.



The Chinese and English names defined above are the ONLY canonical character names used in the final artwork.



Whenever character-name typography appears visually,

use exactly the names defined above.



Do not invent alternate names.

Do not translate or abbreviate them.

Do not replace them with placeholder text.





Create a premium vertical Zenless Zone Zero character editorial poster combining:



a monochrome manga narrative collage,

traditional black ink-brush graphic energy,

multiple character close-up panels,

and ONE dominant full-color foreground character illustration.



The central visual concept is:



THE BACKGROUND TELLS THE CHARACTER'S STORY.



THE FULL-COLOR FOREGROUND CHARACTER REPRESENTS THE CHARACTER IN THE PRESENT MOMENT.



The result should feel like:



a dramatic character chapter cover,

a premium manga character feature page,

a limited-edition anime game poster,

and a stylized character archive page.



ASPECT RATIO:

9:16 vertical.





==================================================

1. CHARACTER IDENTITY — ABSOLUTE HIGHEST PRIORITY

==================================================



Use the provided TARGET CHARACTER reference as the authoritative source for:



facial identity,

face shape,

canonical eye shape,

canonical eye color,

hairstyle,

hair color,

bangs,

side locks,

rear hair structure,

signature ahoge if present,

hair accessories,

headwear,

ear accessories,

jewelry,

canonical outfit identity,

weapons or equipment where relevant,

body proportions,

signature visual motifs,

personality,

and canonical color palette.



The final foreground character must remain immediately recognizable.



Do not redesign the character into a generic anime protagonist.



Do not copy any identity,

face,

hairstyle,

clothing,

or color palette

from the stylistic example artworks.





==================================================

2. CORE VISUAL STRUCTURE

==================================================



Build the poster from THREE clearly separated visual layers.



LAYER 1:

warm off-white manga-paper background.



LAYER 2:

monochrome manga panels,

black ink brushwork,

graphic frames,

and character-name typography.



LAYER 3:

ONE large full-color target character in the foreground.



The foreground character must sit visually ABOVE all manga layers.



Maintain extremely clear hierarchy.



The foreground character should be:



sharpest,

brightest,

most saturated,

and most detailed.



The background manga collage should remain:



lower contrast,

monochrome,

slightly flatter,

and visually subordinate.





==================================================

3. BACKGROUND PAPER

==================================================



Use a warm desaturated paper base.



Possible colors:



ivory,

warm off-white,

pale parchment-beige,

soft cream-gray.



Keep it subtle.



Do NOT create dirty aged paper.



Do NOT add brown stains.



Do NOT add heavy rough paper texture.



The paper should feel like premium manga-print stock,

not damaged antique parchment.





==================================================

4. MANGA COLLAGE BACKGROUND

==================================================



Create several monochrome manga-style images of the SAME TARGET CHARACTER.



All manga panels should depict only the target character.



Possible panel content:



large facial close-up,

extreme eye close-up,

side profile,

serious expression,

calm expression,

battle-focused expression,

small half-body action moment,

weapon-preparation moment,

wind-blown hair moment,

quiet reflective expression.



Do NOT introduce unrelated characters unless absolutely necessary as indistinct silhouettes.



The target character should dominate all narrative fragments.





==================================================

5. LARGE BACKGROUND PORTRAIT

==================================================



Include ONE very large monochrome portrait of the target character in the upper background.



The face may be heavily cropped.



Possible crop:



eyes + forehead,

face from nose upward,

three-quarter facial close-up,

partial profile.



The portrait should occupy a large portion of the upper third.



Use:



black ink linework,

gray screentone,

white paper highlights,

soft cross-hatching.



Keep it behind all foreground elements.





==================================================

6. SECONDARY EYE PANEL

==================================================



Include one wide or diagonal extreme close-up of the target character's eye.



Place it around:



middle-left,

middle-center,

or another compositionally useful region.



This panel can be partially obscured by the foreground character.



Use the eye close-up as a strong narrative motif.



Preserve the target character's canonical eye shape even in monochrome.





==================================================

7. SMALL ACTION PANELS

==================================================



Include approximately 2–4 smaller manga panels.



Possible content:



weapon motion,

profile portrait,

upper-body battle pose,

calm side glance,

hair moving,

equipment close-up,

emotionally restrained expression.



Use irregular panel sizes.



Avoid making every panel a perfect rectangle.



Allow panels to overlap slightly.





==================================================

8. PANEL COMPOSITION

==================================================



Use energetic manga-page geometry.



Use:



diagonal panel boundaries,

cropped frames,

asymmetric placement,

layer overlap,

selected borderless panels.



Avoid:



perfect grid layout,

equal panel sizes,

clean corporate infographic structure.



The collage should feel designed,

but slightly explosive.





==================================================

9. BLACK INK BRUSH LANGUAGE

==================================================



Add expressive black ink brushwork around the manga collage.



Use:



broad dry-brush strokes,

black ink splashes,

sharp calligraphic sweeps,

rough brush edges,

controlled ink droplets,

large black directional marks.



The brushwork should reinforce the composition.



Do NOT cover the foreground character's face.



Do NOT turn the entire poster black.





==================================================

10. CONTROLLED INK TEXTURE

==================================================



Ink effects should be graphic and intentional.



Use several LARGE brush shapes rather than thousands of tiny splatters.



Avoid:



random black noise,

dense speckling,

muddy ink clouds,

dirty paper.



The ink language should remain bold and readable.





==================================================

11. MANGA RENDERING STYLE

==================================================



Render background manga artwork using:



clean black line art,

gray screentones,

controlled cross-hatching,

large black shadows,

white paper highlights,

simple manga shading.



Use strong facial drawing.



Do NOT make manga panels photorealistic.



Do NOT use grayscale 3D renders.



They should look genuinely illustrated.





==================================================

12. BACKGROUND DETAIL CONTROL

==================================================



The manga collage may be complex in composition,

but simple in local texture.



Keep:



faces readable,

eyes readable,

action silhouettes readable.



Avoid excessive micro-detail.



The collage must not become visual noise.





==================================================

13. FOREGROUND FULL-COLOR CHARACTER

==================================================



Place ONE large full-color version of the target character in front of the manga collage.



The foreground character should occupy approximately:



55–70% of the canvas height.



The character may overlap multiple manga panels.



The lower body may extend toward or beyond the bottom edge.



Use a powerful silhouette.



The foreground character should visually burst out of the manga page.





==================================================

14. CHARACTER-ADAPTIVE ACTION — MAJOR PRIORITY

==================================================



Choose the foreground pose according to the target character's personality,

combat style,

equipment,

and visual temperament.



Do NOT copy the exact poses from the style-reference artworks.



The pose should feel specifically designed for the target character.





==================================================

15. ACTION SELECTION — PERSONALITY LOGIC

==================================================



If the target character appears:



CALM / RESERVED / DISCIPLINED:



use a controlled combat-ready pose,

low center of gravity,

weapon held with precision,

quiet focused gaze,

minimal unnecessary movement.



COOL / ALOOF / CONFIDENT:



use a strong diagonal stance,

slight body lean,

one shoulder leading,

weapon or arm creating a bold graphic line,

calm self-assured expression.



ENERGETIC / PLAYFUL:



use a more dynamic forward or sideways movement,

lighter body posture,

larger clothing / hair motion,

playful but battle-ready expression.



ELEGANT / REFINED:



use flowing curved movement,

controlled hand placement,

long fabric / hair / weapon arcs,

graceful three-quarter pose.



MECHANICAL / TECHNICAL:



use equipment,

mechanical parts,

tools,

or weapon geometry

to form strong diagonal shapes.



AGGRESSIVE / DIRECT:



use a stronger forward-facing action silhouette,

weapon closer to foreground,

sharp body direction,

intense but controlled expression.



Choose ONE coherent pose language.





==================================================

16. NO GENERIC ACTION POSE

==================================================



Do NOT automatically use:



generic sword slash,

generic running pose,

generic crouching pose,

generic pointing pose.



The action should be informed by the actual TARGET CHARACTER.



If the character is not weapon-focused,

use body language,

equipment,

hair,

clothing,

or character-specific ability motifs instead.





==================================================

17. STRONG DIAGONAL MOTION

==================================================



Build at least one strong diagonal action line through the foreground character.



Possible sources:



weapon,

arm,

long hair,

coat tails,

ribbons,

mechanical equipment,

body lean,

leg direction.



Preferred major direction:



lower-left → upper-right



or



lower-right → upper-left.



This diagonal motion helps separate the foreground character from the vertical poster.





==================================================

18. CHARACTER SILHOUETTE

==================================================



The foreground silhouette must remain easy to read.



Avoid tangled anatomy.



Separate clearly:



head,

torso,

arms,

weapon / equipment,

major hair masses,

major clothing pieces.



Do not allow manga panels to visually merge with the character silhouette.





==================================================

19. CHARACTER COLOR EXTRACTION

==================================================



Analyze the TARGET CHARACTER reference and identify:



PRIMARY COLOR:

the strongest identity color.



SECONDARY COLOR:

the major supporting color.



ACCENT COLOR:

a smaller signature color.



Keep the foreground character faithful to these colors.



Do NOT automatically use blue.



Do NOT automatically use teal.



Do NOT recolor the character based on the example posters.





==================================================

20. COLOR HIERARCHY

==================================================



The overall poster should use approximately:



65–75%:

warm off-white,

black,

gray,

monochrome manga tones.



20–30%:

target character PRIMARY + SECONDARY colors.



5–10%:

ACCENT color,

small graphic accents,

lighting,

or equipment highlights.



The foreground character should contain almost all of the strong color.





==================================================

21. COLOR BLEED INTO BACKGROUND

==================================================



Allow only VERY SMALL amounts of the character's accent color to appear in the background graphic design.



Possible uses:



one thin manga-panel border,

one tiny underline,

one small geometric symbol,

a tiny brush accent,

small name detail.



Do NOT colorize the entire manga collage.



The monochrome-versus-color contrast must remain strong.





==================================================

22. FOREGROUND LIGHTING

==================================================



Use clean dramatic anime/game lighting on the foreground character.



Use:



clear facial illumination,

strong but controlled hair highlights,

well-shaped clothing shadows,

selected equipment highlights,

small rim-light accents.



The foreground character should visually pop from the paper background.



Do NOT overexpose the character.





==================================================

23. BACKGROUND LIGHTING

==================================================



The manga collage has no independent cinematic light source.



Treat it as printed artwork.



Use:



paper white,

gray tones,

black ink.



Do not apply colorful rim lighting to manga panels.





==================================================

24. DEPTH SEPARATION

==================================================



Create strong depth separation using:



color versus monochrome,

sharp versus flatter rendering,

overlap,

scale,

and contrast.



Do NOT rely heavily on blur.



Manga panels can remain reasonably sharp.



Hierarchy comes primarily from color.





==================================================

25. HAIR MOVEMENT

==================================================



Adapt hair movement to the selected personality and pose.



If the action is dynamic:



allow major hair locks,

ponytails,

braids,

ribbons,

or loose ends

to reinforce the movement direction.



If the character is controlled / reserved:



keep movement more restrained.



Preserve the original hairstyle topology.



Do not invent additional hair structures.





==================================================

26. CLOTHING MOTION

==================================================



Allow:



coat tails,

skirts,

ribbons,

sleeves,

fabric panels,

belts,

or accessories



to reinforce the selected action direction.



Do not create random wind.



Movement should follow the pose.





==================================================

27. WEAPON / EQUIPMENT

==================================================



If the reference character has recognizable weapons or equipment,

preserve their identity.



Use them as part of the composition.



Allow the weapon or equipment to extend diagonally across the poster.



Do NOT replace canonical equipment with a generic sword.



If no weapon exists,

do not invent one unnecessarily.





==================================================

28. CHARACTER EXPRESSION

==================================================



Adapt facial expression to personality.



Possible:



quiet determination,

focused calm,

subtle confidence,

restrained aggression,

playful confidence,

elegant composure,

slightly distant concentration.



Avoid:



generic shouting,

huge open-mouth expression,

random rage,

exaggerated smile.



The face should remain recognizable and controlled.





==================================================

29. LARGE CHINESE NAME TYPOGRAPHY

==================================================



Use the defined Chinese name as a major graphic element.



Place it in an upper corner or upper side area.



Render it using:



bold expressive Chinese brush-calligraphy-inspired typography,

high contrast black ink,

large scale,

strong vertical or stacked composition.



IMPORTANT:



The name must remain legible.



Do not invent extra Chinese characters.



The Chinese name may appear only ONCE.





==================================================

30. ENGLISH NAME TYPOGRAPHY

==================================================



Use the defined English name once as a smaller secondary identity label.



Place it near the large Chinese name or another quiet manga area.



Use:



clean uppercase or title-case Latin typography,

moderate tracking,

minimal serif or restrained sans-serif.



Keep it much smaller than the Chinese name.



The English name may appear only ONCE.





==================================================

31. NO RANDOM LEGIBLE TEXT

==================================================



Do NOT reproduce the Japanese text visible in the style examples.



Do NOT create random readable Japanese,

Chinese,

or English paragraphs.



Do NOT generate fake biographies,

weapon descriptions,

CV names,

or lorem ipsum.



Use ONLY:



the defined character names,

Zenless Zone Zero branding,

and non-legible decorative graphic marks where needed.





==================================================

32. DECORATIVE MICROGRAPHICS

==================================================



Instead of random text,

use small abstract editorial elements such as:



thin rules,

small boxes,

simple circles,

tiny geometric marks,

short nonverbal line clusters,

small emblem-like shapes.



Keep them secondary.





==================================================

33. ZENLESS ZONE ZERO LOGO

==================================================



Include ONE recognizable Zenless Zone Zero logo.



Place it in:



upper-right,

lower-right,

or another visually quiet corner.



Use a monochrome treatment:



black,

charcoal,

or pale character-accent color depending on background.



Keep it smaller than the character name.



Do not place it over the face.



Do not repeat it.





==================================================

34. ZZZ GRAPHIC INTEGRATION

==================================================



Integrate a subtle amount of Zenless Zone Zero visual language through:



small geometric UI-like marks,

restrained industrial linework,

tiny rectangular accents.



Do not overpower the manga / ink visual system.



The poster should remain primarily:



manga editorial collage + character illustration.





==================================================

35. COMPOSITION — UPPER THIRD

==================================================



UPPER THIRD should contain:



large monochrome face close-up,

major Chinese name typography,

one or two manga-panel fragments,

selected black ink brush strokes.



Keep enough light paper area for breathing room.





==================================================

36. COMPOSITION — MIDDLE

==================================================



MIDDLE section should contain:



eye close-up panel,

secondary portrait fragments,

diagonal manga framing,

beginning of foreground full-color character overlap.



Use this region to transition from monochrome storytelling into full color.





==================================================

37. COMPOSITION — LOWER HALF

==================================================



LOWER HALF should be dominated by:



the full-color foreground character,

weapon / equipment,

dynamic clothing or hair,

selected ink strokes behind the silhouette.



Do not overcrowd the lower corners with text.





==================================================

38. OVERLAP

==================================================



Allow the foreground character to overlap:



manga borders,

face close-ups,

brush strokes,

and paper graphics.



However,

do NOT allow black brush strokes to obscure:



eyes,

face,

important weapon grip,

or major identity features.





==================================================

39. PAPER / PRINT TEXTURE

==================================================



Use extremely subtle premium manga-paper character.



Possible:



barely visible fiber,

very fine printing irregularity,

subtle screen-tone effect.



Keep this texture restricted mainly to the monochrome background.





==================================================

40. FOREGROUND CLEANNESS

==================================================



The foreground full-color character must remain extremely clean.



Do NOT apply:



paper grain,

manga dots,

noise,

ink splatter texture,

or print degradation



across the character's skin and hair.



Background texture and foreground rendering must remain separated.





==================================================

41. MANGA SCREENTONE

==================================================



Use controlled screentone only inside selected monochrome panels.



Possible areas:



hair shadows,

cheek shadows,

clothing,

panel backgrounds.



Do not cover the entire page with dot patterns.



Avoid moiré.





==================================================

42. INK BRUSH DIRECTION

==================================================



Align major brush strokes with the foreground action.



If the character motion travels upward-right,

brush strokes should generally support that direction.



If the character uses a curved elegant movement,

use more sweeping arc-shaped strokes.



Ink should reinforce personality.





==================================================

43. PERSONALITY-ADAPTIVE GRAPHIC ENERGY

==================================================



CALM / DISCIPLINED CHARACTER:



cleaner panels,

long controlled brush lines,

more white space,

restrained splashes.



AGGRESSIVE / ENERGETIC CHARACTER:



stronger black brush bursts,

more dramatic diagonals,

slightly denser panel collision.



ELEGANT CHARACTER:



flowing brush curves,

balanced empty space,

refined manga crops.



TECHNICAL / MECHANICAL CHARACTER:



sharper geometric panel cuts,

more rectilinear graphic marks,

controlled industrial framing.



Adapt the entire poster rhythm,

not only the pose.





==================================================

44. VISUAL HIERARCHY

==================================================



Strict priority:



1. full-color foreground character face,

2. full-color action silhouette,

3. large monochrome background face,

4. large Chinese character name,

5. eye close-up / manga panels,

6. weapon / equipment,

7. black brushwork,

8. English name,

9. Zenless Zone Zero logo,

10. small decorative graphics.



Maintain this hierarchy clearly.





==================================================

45. CONTRAST CONTROL

==================================================



Keep background manga contrast strong enough to read,

but lower than the foreground.



Avoid pure-black manga masses directly behind dark parts of the foreground character.



Use paper-white gaps around critical silhouette regions.





==================================================

46. NEGATIVE SPACE

==================================================



Do not fill every region.



Preserve selected off-white paper gaps.



Use negative space around:



character face,

name typography,

weapon silhouette.



This keeps the composition readable despite collage complexity.





==================================================

47. CAMERA / FOREGROUND CHARACTER

==================================================



Use a dynamic but believable anime-game camera.



Depending on personality and pose:



slightly low angle,

subtle three-quarter perspective,

or controlled eye-level dynamic view.



Avoid extreme fisheye.



Avoid distorted anatomy.



The camera should strengthen the pose rather than become the subject.





==================================================

48. ANATOMY

==================================================



Maintain accurate:



face,

neck,

shoulders,

torso,

arms,

hands,

legs.



Correct five-finger anatomy where hands are visible.



Weapon grips must make physical sense.



Avoid twisted limbs caused by diagonal composition.





==================================================

49. CLEAN RENDERING / IMAGE QUALITY

==================================================



FOREGROUND CHARACTER:



extremely clean polished anime/game rendering,

smooth controlled color transitions,

clean cel-influenced shading,

precise facial features,

large coherent color regions,

smooth anime skin,

clean hair locks,

controlled shadows,

sharp equipment edges,

professional commercial finish.



BACKGROUND:



clean manga line art,

controlled screentones,

intentional ink,

off-white paper,

no uncontrolled noise.



Avoid:



digital noise,

film grain,

chromatic grain,

luminance grain,

random colored pixels,

dirty speckles,

heavy rough paper,

canvas texture,

random microtexture,

skin pores,

noisy individual hair strands,

muddy gradients,

blotchy shading,

dirty color transitions,

JPEG artifacts,

compression artifacts,

oversharpening halos,

excessive microcontrast.





==================================================

50. CRITICAL MANGA COLLAGE CHECK

==================================================



Before finalizing:



the background must clearly read as a collage of manga panels featuring the SAME character.



It should NOT read as:



random grayscale photographs,

random unrelated anime characters,

or generic abstract ink.



At least:



one large face,

one eye close-up,

and two smaller character panels



should be visually recognizable.





==================================================

51. CRITICAL COLOR CHECK

==================================================



The foreground character should be the primary source of color.



If the manga background becomes strongly colorful,

desaturate it back toward:



black,

gray,

off-white.



Only very small accent-color contamination is allowed.





==================================================

52. CRITICAL ACTION CHECK

==================================================



The foreground pose must feel appropriate to the TARGET CHARACTER's personality.



If the pose feels like a generic action-template pasted onto the character,

redesign it.



Use the character's:



temperament,

combat style,

equipment,

and silhouette



to determine movement.





==================================================

53. CRITICAL TEXT CHECK

==================================================



Use the defined Chinese name ONCE.



Use the defined English name ONCE.



Use ONE Zenless Zone Zero logo.



Do not generate additional random readable text.



Do not reproduce text from the style-reference images.





==================================================

54. CRITICAL CLEANLINESS CHECK

==================================================



Complex composition does NOT mean dirty rendering.



The poster can contain:



many panels,

ink strokes,

brush marks,



while still maintaining clean large shapes.



Avoid tiny random speckles everywhere.



Avoid texture overload.



Keep intentional separation between:



paper,

ink,

manga,

and full-color character.





==================================================

55. FINAL TARGET

==================================================



9:16 vertical Zenless Zone Zero character editorial poster.



One TARGET CHARACTER only.



Large full-color foreground character.



Dynamic personality-matched action.



Strong diagonal silhouette.



Canonical character identity preserved.



Canonical character palette preserved.



Background composed of multiple monochrome manga images of the same character.



One huge monochrome face close-up.



One eye close-up.



Two to four smaller manga panels.



Warm off-white manga-paper base.



Black and gray screentone artwork.



Bold controlled black ink-brush strokes.



Selected ink splashes.



Strong monochrome-versus-color contrast.



Foreground character sharp,

clean,

bright,

and saturated.



Background manga flatter and monochrome.



Large brush-calligraphy-inspired Chinese character name.



Small restrained English character name.



One small Zenless Zone Zero logo.



No random Japanese text.



No random biographies.



No unrelated characters.



No noisy paper texture.



No dirty grain.



No excessive microdetail.



Premium,

dramatic,

graphic,

manga-editorial,

character-focused,

chapter-cover atmosphere.
